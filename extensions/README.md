# Extensions (layercake)

Opt-in capabilities outside the default `game` profile diet.

| Path | Contents |
|------|----------|
| `extensions/generative/` | FLUX, TRELLIS, genetic GAN client |
| `extensions/research/` | RadiusFPS, DaX, GCC-FER, x3DPRA, … |

**Phase 5c:** canonical tree is physical here. `src/extensions` forwards to this directory for one release.

CMake: `IDTECH3_DIR_EXTENSIONS` in [`cmake/IdTech3Layout.cmake`](../cmake/IdTech3Layout.cmake).
