# C23 Modernization

This document describes the C23 modernization of the idTech3 engine, including language features adopted, compatibility considerations, and build requirements.

## Overview

The idTech3 engine has been modernized to use C23 language features while maintaining full backward compatibility with existing mods and the Quake III Arena ecosystem.

## C23 Features Adopted

### Core Language Features

- **Static Assertions**: Using `_Static_assert()` for compile-time validation
- **Modern Macros**: Leveraging `__VA_OPT__` for variadic macro improvements
- **Boolean Types**: Native `bool` support from `<stdbool.h>`
- **Designated Initializers**: Enhanced struct initialization syntax
- **Compound Literals**: Improved literal syntax for complex types

### Compatibility Layer

The `src/qcommon/q_compat.h` header provides:

- **STATIC_ASSERT macro**: Cross-compiler static assertion support
- **ARRAY_LEN macro**: Safe array length calculation
- **FALLTHROUGH macro**: Explicit fallthrough annotation for switch statements
- **MIN/MAX macros**: Type-safe min/max operations
- **LIKELY/UNLIKELY macros**: Branch prediction hints

## Build Requirements

### Compilers

- **GCC**: 15.0+ with C23 support

- **MSVC**: 2022+ (Visual Studio 17.0+)

### Build System

- **CMake**: 3.20+ minimum

- **Linux**: Fully supported with GCC/Clang

### Code Patterns

```c
// Modern C23 with fallback
#ifdef __STDC_VERSION__
#if __STDC_VERSION__ >= 202311L
// C23 specific code
#define DROP(reason, ...) \
    do { \
        VM_FreeBuffers(); \
        Com_Error(ERR_DROP, "%s: " reason, __func__ __VA_OPT__(,) __VA_ARGS__); \
    } while(0)
#else
// C99/C11 fallback
#define DROP(reason, ...) \
    do { \
        VM_FreeBuffers(); \
        Com_Error(ERR_DROP, "%s: " reason, __func__, ##__VA_ARGS__); \
    } while(0)
#endif
#endif

// Static assertions
STATIC_ASSERT(sizeof(void*) == 8, "64-bit pointers required");

// Type-safe operations
bool is_valid = (size_t)count < ARRAY_LEN(buffer);
```
