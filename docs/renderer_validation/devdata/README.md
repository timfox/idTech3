# Renderer regression devdata (minimal dedicated-server pack)

This directory holds a **minimal** game tree (`rtest_base/`) so `renderer_regression_check.sh` and `renderer_regression_maps.sh` can run without a full commercial game pak. Use **`GAME_BASE`** pointing at `rtest_base` (same layout as a normal `base/` folder).

## Contents (after build)

- `rtest_base/maps/rtest_*.bsp` — IBSP v46 collision-only stubs from `scripts/tools/gen_rtest_bsp.py` (not visual regression geometry; replace with real maps when authored).
- `rtest_base/vm/qagame.qvm` — from **ioquake3** (GPL); not generated by this repo.
- `rtest_base/default.cfg` — `bot_enable 0` so dedicated init does not require botlib scripts.
- `rtest_base/z_renderer_regression.pk3` — zip of the above for pak-based installs.

## Build

From the repo root:

```bash
./scripts/build_renderer_devdata.sh
```

Set `QAGAME_QVM` or `IOQ3_BUILD` if `qagame.qvm` is not at `/tmp/ioq3-check/build/Release/baseq3/vm/qagame.qvm`.

## Validate

```bash
export GAME_BASE="$PWD/docs/renderer_validation/devdata/rtest_base"
export GAME_ASSETS_LIST="$PWD/docs/renderer_validation/devdata/OPTIONAL_GAME_ASSETS.txt"
./scripts/renderer_regression_check.sh
./scripts/renderer_regression_maps.sh
```

## Honest scope

These BSPs prove **CM_LoadMap + qagame InitGame** on dedicated. They do **not** prove Vulkan frame output, volumetric appearance, or parity until replaced with authored regression maps and run under the client.
