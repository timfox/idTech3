# G-Buffer Quality

`r_gbufferQuality` 0=compact 1=balanced 2=full-fidelity IQ reference.  
IQ reference requires `r_gbufferCompact 0`.

Commands: `gbuffer_quality_status` · `gbuffer_memory_status`.

See [DEFERRED_HONESTY.md](DEFERRED_HONESTY.md), [RENDERER_IQ_REFERENCE_PROFILE.md](RENDERER_IQ_REFERENCE_PROFILE.md).
